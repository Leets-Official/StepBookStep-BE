**만만한 책으로, 탄탄한 습관까지**  

나조차 나의 독서 취향을 모른다면, 독서에 재미를 붙이기란 쉽지 않아요.  
내 수준에 딱 맞는 책과 스스로 설정한 작은 목표가 함께 한다면 어느 순간 한 단계 성장한 나를 발견하게 될 거예요.  

스텝북스텝은 **나에게 맞는 한 권**을 더 쉽게 찾고, **독서를 일상의 루틴으로 정착**시키기 위해 탄생했습니다.
