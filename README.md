# 📚 StepBookStep
> **개발 기간**: 2025.12.22 ~ 2026.02.14

‘스텝북스텝’은 ‘Step by Step’에서 착안한 이름으로, 책을 통해 한 단계씩 성장한다는 의미를 담고 있습니다.
 계단의 이미지를 통해 독서를 한 번의 결심이 아닌, 차근차근 쌓아가는 과정으로 바라보는 브랜드의 철학을 표현했습니다.
 스텝북스텝이 제공하는 단계별 난이도 설계와, 목표 달성을 통한 루틴의 축적 과정을 시각적으로 형상화했습니다.
